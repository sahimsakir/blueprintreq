# BlueprintReq

AI Product Development Assistant UI demo.

## Run locally

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Vercel

Import sahimsakir/blueprintreq with repository root as the root directory. vercel.json selects the prebuilt dist folder; no build command is required.

This is a static UI prototype. AI, authentication, meeting integrations and shared persistence require backend services.
